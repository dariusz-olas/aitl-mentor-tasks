# aitl-mentor-tasks

Projekt wyróżnienia **AI Tech Leaders** — mini tracker zadań mentoringowych (ścieżka B).

## Start lokalny

1. `npm ci` (lub `npm install`)
2. `npm test`
3. `npm run build`
4. `npm run dev` → http://localhost:3000
5. Konta demo: dołożymy w F3 (Auth.js) — placeholder w `docs/REVIEWER.md`
